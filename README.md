# Hacker House Goa 2026 - Builder ID Card Generator

A modern, fully responsive React web application built for the **Hacker House Goa 2026 Builder ID Card Generator** (Format B Task).

**Developed by T.Sathvik**

---

## ⚡ Features

- **Interactive 3D WebGL Background**: Three.js particle clouds, orbiting 3D cubes, and floating geometry with mouse-parallax.
- **Gyroscopic 3D Card Stage**: 3D mouse tilt, 3D card flip, exploded 3D layers, and 3D holographic rainbow foil sheen.
- **1200x675 HD 16:9 Canvas**: Live client-side rendering with zero server processing or sign-in gates.
- **iPhone HEIC Image Processing**: Native client-side conversion of `.heic` photos to `.jpg` using `heic2any`.
- **Hacker House Goa Branding**: Rich Green (`#0c6838`), Hot Pink (`#ff007a`), Sunset Gold (`#facc15`), and official Devanagari `"गोवा"` SVG logo.
- **Title Randomizer**: Shuffle through titles like *Chain Architect*, *GPU Whisperer*, *Zero-Knowledge Ninja*, *Protocol Hacker*.
- **Export & Share**: 1-click HD `.png` download with celebratory confetti and pre-filled X (Twitter) sharing with `#FrameInGoa`.

## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```

---

## 🚀 Deployment Steps (Vercel / Netlify)

1. Push this repository to GitHub.
2. Connect your GitHub repository to **Vercel** or **Netlify**.
3. Set the build settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**!
